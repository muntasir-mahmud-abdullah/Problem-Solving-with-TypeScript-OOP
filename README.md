# Problem Solving with TypeScript & OOP

This repository contains my solutions for the **Problem Solving with TypeScript & OOP**. The focuses on applying core TypeScript concepts, problem-solving techniques, and Object-Oriented Programming (OOP) principles through practical exercises and technical blog writing.


### 1. Problem Solving

Implemented eight TypeScript problems covering:

- Optional parameters and default values
- Union types and type narrowing
- Readonly tuples
- Generics and rest parameters
- Interfaces and array filtering
- `keyof` constraints and generic property access
- OOP concepts, inheritance, and access modifiers
- Asynchronous programming with Promises and error handling

### 2. Technical Blog Posts 

Two technical blog posts explaining TypeScript concepts with practical code examples:

1. [Type vs Interface](./type-vs-interface.md)
2. [Type Narrowing](./type-narrowing.md)
